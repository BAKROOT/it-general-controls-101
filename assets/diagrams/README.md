# Diagrams

This folder holds images (diagrams, screenshots) referenced by the documentation.

It's optional — the chapters use simple ASCII/text diagrams inline so the knowledge base is fully readable without any images. If you'd like to contribute richer visuals (for example, a diagram of the layered control model or the change-management flow), add them here and reference them from the relevant `docs/` file, e.g.:

```markdown
![Layered control model](../assets/diagrams/layered-model.png)
```

See [CONTRIBUTING.md](../../CONTRIBUTING.md) for guidance.
